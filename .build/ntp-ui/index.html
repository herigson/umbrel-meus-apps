Como apontar seus dispositivos

Servidor NTP em este Umbrel, porta 123/UDP.

MikroTik (roteador + toda a rede via DHCP) 
/system ntp client set enabled=yes servers=IP_DO_UMBREL
/ip dhcp-server network set [find] ntp-server=IP_DO_UMBREL
Windows (ignora a option 42 do DHCP) 
w32tm /config /manualpeerlist:IP_DO_UMBREL /syncfromflags:manual /update
w32tm /resync
w32tm /stripchart /computer:IP_DO_UMBREL /samples:3
Linux (systemd-timesyncd) 
# /etc/systemd/timesyncd.conf
[Time]
NTP=IP_DO_UMBREL
